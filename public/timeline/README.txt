Timeline photos go in this folder.

1. Drop an image here, e.g. 2014.jpg (landscape, roughly 4:3, ~1200px wide is plenty).
2. In src/content.js, find that year in `timeline` and set its photo src:
     photo: { src: '/timeline/2014.jpg', caption: 'youth digital minecraft mod' },
The caption is used as the image's alt text.
